# cyber-lab

Laboratorio de ciberseguridad y redes montado en VMware Workstation Pro. Cada lab documenta una práctica con su predicción previa, los pasos, las capturas y lo aprendido.

## Entorno

- Host: portátil con VMware Workstation Pro 17.6.4
- Atacante: Kali Linux 2026.2 (NAT + Host-only)
- Víctima: Ubuntu Server 24.04 (NAT + Host-only)
- Red del lab: Host-only VMnet1, `192.168.163.0/24`

## Método de cada lab

1. Escribir una predicción antes de ejecutar nada.
2. Ejecutar los pasos y capturar la evidencia.
3. Comparar el resultado con la predicción y explicar por qué.
